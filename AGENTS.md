# Project instructions

## Project

- Deliver a static personal portfolio page with HTML, CSS, and native JavaScript.
- Keep the recovered page as a single `index.html`; do not introduce a framework or build pipeline unless requested.
- Preserve its visual design and GSAP/ScrollTrigger/Lenis behavior when making changes.

## Commands

- Local preview: `python -m http.server 8767 --bind 127.0.0.1`
- Build: none; the page is served directly.
- Verification: open the page in a browser and inspect scroll behavior, responsive layout, and console.

## Git and safety

- Keep only portfolio files in this repository.
- Never commit credentials, local environment files, or machine specific configuration.
- Check the staged diff before each commit and push.
