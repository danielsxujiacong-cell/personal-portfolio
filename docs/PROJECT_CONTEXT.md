# Project context

A single index.html portfolio with five sections: Hero, Featured Work, Selected Products, How I Build, About & Contact. Preserve the dark design and real product previews. No framework, WebGL, iframe or build pipeline.

GSAP/ScrollTrigger provides short reversible reveals. Lenis is desktop-only and runs briefly on wheel activity. Reduced motion and unavailable dependencies leave content visible. All non-hero images are lazy-loaded WebP with intrinsic sizes.

Real screenshots originate from the local Hub public/projects directory and the existing flagship assets. Hub is read-only reference material and is not modified.
